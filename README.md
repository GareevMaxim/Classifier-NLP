# Классификация отзывов на фильмы IMDB (50k Movie Reviews)

## Описание проекта
Данный проект посвящен задаче бинарной классификации текста (Sentiment Analysis) на популярном датасете IMDB (50 000 строк). Цель работы — построить и сравнить классические алгоритмы машинного обучения (деревянные модели) и глубокие нейросети (PyTorch) для определения тональности отзыва (positive / negative).

---

## Архитектура и структура проекта

Проект организован в виде модульной структуры, разделяющей аналитику, предобработку данных, вычисление моделей и оценку результатов:

*   `1_baseline.ipynb` — Ноутбук с экспериментами классического ML (эксперименты с векторайзерами и деревьями).
*   `2_neural_networks.ipynb` — Ноутбук с пайплайнами глубокого обучения на PyTorch.
*   `nlp.py` — Модуль текстовой аналитики (токенизация через `tiktoken`, фильтрация, расчет ANOVA F-value и Mutual Information для N-грам, а также кастомный класс `IMDBDataset` для PyTorch).
*   `transformers.py` — Реализация Scikit-Learn совместимых трансформеров `NgramFeatureSelector` (отбор топ-K признаков) и `SequenceVectorizer` (индексация и паддинг последовательностей).
*   `models.py` — Описание Pydantic-схем валидации метрик качества и архитектур нейросетей (`TextCNNClassifier`, `LSTMClassifier`, `RNNClassifier`, `GloVeTextCNNClassifier`).
*   `helper.py` — Универсальные циклы обучения (`train`/`evaluate` для PyTorch) и функции агрегации кросс-валидационных метрик.
*   `plots.py` — Визуализация результатов (матрицы ошибок, ROC-кривые, сводные хитмапы).

## Проведенные эксперименты и Сценарии

### ЧАСТЬ 1: Классический ML (Кросс-валидация на 3 фолда)
Тестировались модели: `DecisionTreeClassifier`, `RandomForestClassifier`, `LGBMClassifier`.
1.  **CountVectorizer (Без очистки)**: Топ-5000 частых слов, включая стоп-слова.
2.  **CountVectorizer (+ StopWords)**: С фильтрацией английских стоп-слов.
3.  **Топ-100 Важных Токенов**: Отбор признаков по ANOVA F-value через кастомный `NgramFeatureSelector`.
4.  **TfidfVectorizer (Без очистки)**: Непрерывные веса признаков топ-5000 слов.
5.  **TfidfVectorizer (+ StopWords)**: Взвешивание признаков с удалением шума.

### ЧАСТЬ 2: Глубокое обучение (PyTorch, 5 эпох)
1.  **Text-CNN (С нуля)**: Сверточная сеть с параллельными окнами (3, 4, 5 слов).
2.  **Text-CNN + GloVe**: Использование предобученных замороженных эмбеддингов Stanford (100d).
3.  **LSTM**: Рекуррентная сеть с учетом последовательного контекста.
4.  **RNN**: Базовая рекуррентная модель для оценки затухания градиентов.

## 📈 Результаты и выводы

### Сводная таблица лучших моделей:

| Модель | Архитектура / Признаки | Accuracy | ROC AUC |
| :----------------| :-------------------- ---| :---------| :---------|
| **PyTorch (DL)** | **Text-CNN (С нуля)**    | **88.7%** | **0.953** |
| PyTorch (DL)     | Text-CNN + GloVe         | 86.3%     | 0.941     |
| **LightGBM (ML)**| **TF-IDF (No StopWords)**| **86.2%** | **0.939** |
| LightGBM (ML)    | TF-IDF + StopWords       | 85.9%     | 0.936     |
| Random Forest    | TF-IDF (No StopWords)    | 83.0%     | 0.912     |
| LightGBM (ML)    | Top-100 Tokens Selector  | 82.7%     | 0.909     |
| PyTorch (DL)     | LSTM                     | 82.5%     | 0.932     |
| PyTorch (DL)     | RNN                      | 71.9%     | 0.791     |

### Ключевые выводы:
*   **Победитель — Text-CNN (С нуля)**. Сверточные слои идеально фиксируют устойчивые словосочетания (N-граммы) в эмоциональных отзывах, обгоняя рекуррентные сети по скорости и точности.
*   **Эффективность LightGBM**. Классический градиентный бустинг в связке с TF-IDF показал себя как мощный и стабильный бейзлайн (86.2%), минимально уступая нейросети.
*   **Сжатие признаков**. Кастомный трансформер отбора признаков по стат-критериям доказал работоспособность: сокращение словаря до 100 токенов сохранило точность бустинга выше **82.7%**, кратно снизив потребление памяти.
